# Reference

Generated by autodoc from the installed package, so these pages describe
`herascrape` {{ release }} exactly as it behaves.


The two client classes carry the same 39 endpoint methods and the same
`iter_*` helpers; {class}`~herascrape.AsyncClient` returns awaitables and
async iterators. Method names are the endpoint path in `snake_case`, and each
method's docstring names the path it calls.

Every name is in the {ref}`index <genindex>`, which is the fastest way to
find a method when you already know what you are looking for.
